# スタッフ確認フロー

## 目的

谷田部がLINE返信を抱え込まない。ただしスタッフに保護者返信を任せない。

スタッフは「候補日時・場所・担当可否・補足」だけ返す。
保護者向け文章はAI秘書が作り、谷田部が確認して送る。

## 今日使うURL

```text
https://soccer-diagnosis.vercel.app/admin/ai-secretary/staff-checks?token=AI_SECRETARY_READ_TOKEN
```

## 谷田部がやること

1. `スタッフ確認` 画面を開く
2. 対象カードの `スタッフへLINE通知` を押す
3. スタッフ返信がAI秘書に取り込まれる
4. 生成された保護者向け下書きを谷田部が確認して送る

顧客への自動送信はしない。

## 初回だけスタッフがやること

通知を受け取りたいLINE公式アカウントへ、スタッフ本人から以下を送る。

```text
スタッフ登録 野間
```

登録に成功すると、AI秘書が以下のように返信する。

```text
スタッフ登録しました。
名前: 野間
このLINEに日程確認が届くようになります。
```

## スタッフへ自動Pushされる内容

```text
【スタッフ確認 / TASK:123】

顧客:
LINE公式:
受信:

保護者から日程相談が来ています。

内容:

確認してほしいこと:
・対応可能な候補日時
・場所
・担当可能か
・注意点があれば一言

返信はこの形式でお願いします。
先頭の TASK:123 は消さないでください。

TASK:123
候補:
不可:
場所:
補足:
```

## スタッフ返信の取り込み

スタッフが以下の形式で返信すると、AI秘書が保護者向け返信下書きを更新する。

```text
TASK:123
候補: 7/25(土) 10:00、7/26(日) 14:00
不可: 7/24(金)
場所: しながわ区民公園
補足: 雨天時は前日確認
```

取り込み成功時、スタッフには以下を返す。

```text
確認内容をAI秘書に取り込みました。谷田部確認用の返信下書きに反映します。
```

## スタッフにやらせないこと

- 保護者への返信文作成
- 日程確定
- 回数券の確定
- 料金案内
- 契約案内
- 退会対応
- クレーム対応

## 次に自動化すること

- 30分未返信リマインド
- 2時間未返信でMorning画面へ緊急表示

## 本番DB

まだ実行していない場合は、Supabase SQL Editorで実行する。
