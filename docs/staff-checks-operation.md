# スタッフ確認フロー

## 目的

谷田部がLINE返信を抱え込まない。ただしスタッフに保護者返信を任せない。

スタッフは「候補日時・場所・担当可否・補足」だけ返す。
保護者向け文章はAI秘書が作り、谷田部が確認して送る。

## 今日使うURL

```text
https://soccer-diagnosis.vercel.app/admin/ai-secretary/staff-checks?token=AI_SECRETARY_READ_TOKEN
```

## 谷田部がやること

1. `スタッフ確認` 画面を開く
2. 対象カードの `スタッフ確認文をコピー` を押す
3. スタッフLINEに貼る
4. スタッフから返ってきた候補を見て、AI下書きに反映して送る

## スタッフに送る内容

```text
【日程確認依頼】

顧客:
LINE公式:
受信:

保護者から日程相談が来ています。

内容:

確認してほしいこと:
・対応可能な候補日時
・場所
・担当可能か
・注意点があれば一言

以下だけ返信してください。

候補:
不可:
場所:
補足:
```

## スタッフにやらせないこと

- 保護者への返信文作成
- 日程確定
- 回数券の確定
- 料金案内
- 契約案内
- 退会対応
- クレーム対応

## 次に自動化すること

- `staff_members` 登録
- スタッフLINE userId取得
- AI秘書からスタッフへ内部LINE Push通知
- 30分未返信リマインド
- 2時間未返信でMorning画面へ緊急表示

## 本番DB

SQLは `supabase/phase-staff-checks.sql` に保存。

まだ実行していない場合は、Supabase SQL Editorで実行する。
