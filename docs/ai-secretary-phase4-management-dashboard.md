# AI秘書 Phase4 AI経営ダッシュボード

## 目的

谷田部が毎朝見るだけで、今日やるべき顧客対応と売上対応が分かる状態を作る。

自動送信はしない。
LINE送信もしない。
メール送信もしない。

Phase4では以下まで。

- 保存
- 分析
- 表示
- 手動管理

## Gmail連携準備

`gmail_sync_sources` に以下を追加。

- direction
- status
- needs_reply
- ai_summary
- ai_reply_draft

本番OAuth接続後、問い合わせメールと未返信メールをここへ保存する。
顧客マスタに紐付いたものは顧客タイムラインにも追加する。

## Googleカレンダー連携準備

`calendar_sync_sources` に以下を追加。

- event_type
- status
- ticket_usage_candidate
- ai_summary

本番OAuth接続後、レッスン予定と実施履歴をここへ保存する。
実施済み予定は回数券消化候補として表示する。

## AIフォロー文

現段階では下書き生成の準備として、画面上に以下を表示する。

- LINE返信文
- メール返信文
- 次にやること

外部送信はしない。
