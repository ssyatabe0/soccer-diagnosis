# サッカー症例データベース β

## 症例を追加する

1. 管理画面の「症例DB」でカルテを追加する。
2. 元動画、公開許可、学年、改善時間を確認する。
3. `data/cases.ts` に公開用レコードを追加する。
4. 確認できない項目は `null` にする。推測で補わない。
5. 日本語と英語を同じレコードへ保存する。
6. `npm run build` で個別ページ、サイトマップ、構造化データを検証して公開する。

機械連携用の定義は `data/case.schema.json`、公開データの読み取り口は `GET /api/cases`。

## 自動化の接続点

既存の `POST /api/ai-secretary/cases` はフルレッスン動画から生成した非公開カルテの保存先として使う。公開前の人による確認を残し、確認後に共通症例データへ昇格する。

動画分割が完了したら `before_video` と `after_video` に個別URLを入れる。現状の公開済みショートは `comparison_video` として保持する。
